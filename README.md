# 键程 · 打字练习工作台

一个**单文件、纯前端、可离线使用**的打字练习网站。全部界面、练习引擎、统计逻辑与内置素材都写在 `index.html` 里，双击即可打开，不需要安装、不需要联网、不需要构建。

- 界面语言：简体中文
- 交付形态：单个自包含 `index.html`（约 150 KB / 3100 行）
- 浏览器要求：Chrome / Edge / Firefox 等现代浏览器（含 localStorage 与 ES5 环境即可）

---

## 1. 这个项目解决什么问题

想练打字的人常遇到的几个障碍：

| 常见问题 | 本项目对应的做法 |
| --- | --- |
| 不知道从哪练起，东打一段西打一段 | 4 级课程从基准键位排到文章段落，逐级推进并有星级记录 |
| 只知道自己"打得慢"，不知道错在哪 | 逐字符实时高亮 + 错键统计，直接指出最常打错的键位与错误类型 |
| 练完没有量化反馈，进步看不见 | 每次练习落库：净速度、正确率、用时、击键/错误数，并绘制趋势图 |
| 找不到合适的练习材料 | 内置 20 篇分类素材（文章 / 代码 / 公文 / 诗词 / 专业词汇），也可粘贴自己的文本 |
| 网上打字网站要注册、有广告、必须联网 | 完全离线单文件运行，无账号、无广告、无网络请求，数据只在本机 |
| 中文录入练习工具少 | 中文内容走拼音输入法整字提交路径（`isComposing` / `composition` 防护），按「字/分」计量 |

目标是给出一套**可自我驱动、可量化、能长期使用**的打字训练环境。

## 2. 主要功能

### 2.1 七大视图（左侧导航，`Alt + 1…7` 直达）

| # | 视图 | 说明 |
| --- | --- | --- |
| 1 | 练习模式 | 练习工作台：实时指标 + 逐字符高亮文本 + 虚拟键盘 + 结果面板 |
| 2 | 分级课程 | 四级进阶路线与星级记录 |
| 3 | 专项训练 | 易错键强化 / 提速冲刺 / 盲打强化 / 弱键排行 |
| 4 | 素材库 | 内置分类素材 + 自定义素材导入 |
| 5 | 单词雨 | 下落单词消除游戏 |
| 6 | 考试模拟 | 限时测评与成绩单 |
| 7 | 数据统计 | KPI、趋势图、错误类型、键位热力图、弱键排行、最近记录 |

### 2.2 练习引擎与实时反馈

- **逐字符比对**：正确字符、错误字符、当前光标位分别着色；错误状态除颜色外还有下划线与图标，不依赖单一颜色通道。
- **实时指标**：净速度、正确率、已用时长、进度（`已输入 / 总字符`）、错误计数；限时模式下显示剩余时间。
- **指标口径**（代码内真实算法）：
  - 净速度 WPM = `正确字符数 ÷ 5 ÷ 分钟数`
  - 中文速度 = `正确字符数 ÷ 分钟数`（字/分）
  - 正确率 = `(总击键 - 错误击键) ÷ 总击键 × 100%`，按击键统计而非按最终文本
- **严格模式**：开启后一旦打错即阻止继续输入，必须先退格改正。
- **退格回改**：允许随时修改，未开严格模式时错误不会中断输入流。
- **自动滚屏**：文本跟随光标位置纵向滚动，长文练习不用手动找位置。
- **键击音效**：Web Audio 合成短音（正确音 / 键音 / 错误音），可一键开关。
- **虚拟键盘**：QWERTY 布局，下一键高亮提示、按下反馈、错误热力着色，可整体隐藏。

### 2.3 分级课程（4 级 / 19 课）

| 级别 | 名称 | 内容 | 课数 |
| --- | --- | --- | --- |
| LEVEL 1 | 基础键位 | 基准键位、上排、下排、数字排、大写与 Shift、常用标点、全键位综合 | 7 |
| LEVEL 2 | 英文单词 | 高频短词、常用长词、词组搭配、标点混排、数字混合 | 5 |
| LEVEL 3 | 中文短句 | 日常短句、办公用语、中英混排 | 3 |
| LEVEL 4 | 文章段落 | 散文名篇、新闻消息、说明文段、中英混排段落 | 4 |

每课记录历史最佳成绩并换算星级（正确率 90% / 96% / 99% 逐级加星；中文 ≥ 80 字/分或英文 ≥ 40 WPM 且正确率 ≥ 96% 时封顶 5 星）。课程页显示每级完成百分比，「继续上次」直接回到上次练习的课程。

### 2.4 专项训练

- **易错键强化**：从历史错键统计中取最常出错的键位，自动生成组合序列作为练习文本（数据不足时会提示先完成几组练习）。
- **提速冲刺**：60 / 120 / 180 秒限时输入高频词表，倒计时结束后自动结算。
- **盲打强化**：可选择隐藏文本、隐藏键盘或两者同时隐藏，凭节奏与肌肉记忆输入，结束后整体对照结果。
- **弱键排行**：基于最近 30 次记录列出错误率最高的 10 个键位。

### 2.5 素材库

- 内置 5 类共 20 篇素材：热门文章（朱自清、老舍等公版节选）、代码片段（Python / JavaScript / C / SQL）、公文范本（仿写）、诗词名篇（李白、徐志摩、苏轼等）、专业词汇（计算机 / 法律 / 财务 / 学术中英对照）。
- **自定义素材**：粘贴任意中英文文本并保存（20–5000 字符；超过 600 字符会按空行自动拆成多段），可命名、可删除、可一键开始练习，并自动出现在练习内容下拉框中；语言按是否含中文自动判定。

### 2.6 单词雨游戏

- 英文单词从顶部落下，完整键入即击落（不区分大小写），可退格修正。
- HUD 显示得分、连击、击落数、生命值（3 条命，漏掉 3 个单词结束）。
- 三档难度（悠闲 / 标准 / 极速）对应不同的下落速度、生成间隔与同屏上限，难度随时间递增。
- 结算显示得分、击落数与最高连击，`Esc` 可随时暂停；游戏记录同样进入历史统计。

### 2.7 考试模拟

- 试卷设置：时长 3 / 5 / 10 分钟，范围可选综合（英文 + 中文）/ 英文段落 / 中文段落 / 代码片段；试卷由内置课程与素材库文本拼装而成。
- 考试中**不显示即时对错**（关闭实时着色与错误音），允许退格修改，显示倒计时、已输入字数、字/分与进度条。
- 支持「提前交卷」，交卷或计时结束生成成绩单：净速度、正确率、完成字数、击键/错误数、评级（A / B / C / D）、最多 50 条逐字错误明细，并可「用这份试卷练习」。

### 2.8 数据统计

- KPI 条：平均速度、平均正确率（统计最近 30 次，**不计入单词雨游戏局**）、累计练习分钟、练习次数（含游戏与考试）、历史最佳速度。
- **趋势图**：最近 14 次练习的速度与正确率双线折线图（内联 SVG 手绘），并附隐藏表格与 `aria-label` 供读屏使用。
- **错误类型分布**：把错误归类为「大小写 / 相邻键误触 / 标点 / 其他」四类做条形占比。
- **键位热力图**：整块键盘按错误次数着色，悬停查看明细。
- **弱键排行表**：键位、击键数、错误数、错误率、占比。
- **最近记录表**：最近 12 次练习 / 游戏 / 考试的时间、模式、内容、速度、正确率、用时。

### 2.9 个性化与可访问性

- 浅色 / 深色主题（默认跟随系统 `prefers-color-scheme`，首帧前脚本应用主题避免闪烁）。
- 练习字号（小 / 中 / 大）、界面密度（紧凑 / 标准 / 宽松）、圆角风格（硬朗 / 默认 / 圆润）三组可调项。
- 莫兰迪配色：种子 token（`--seed-*`）集中声明颜色，其余样式通过 `var()` / `color-mix()` 派生。
- 响应式：1180px / 980px / 720px 三档断点，桌面优先且窄屏不横向溢出。
- 尊重 `prefers-reduced-motion`，表单控件带 label / `aria-label`，关键状态通过 `aria-pressed`、`aria-live` 播报。

## 3. 安装方法

本项目**没有依赖、没有构建步骤**，所谓"安装"只是把文件放到本地并打开。

### 方式 A：直接使用（推荐）

1. 把 `index.html` 放在任意本地目录（当前为 `D:\打字练习网站\`）。
2. 双击 `index.html`，或在浏览器中按 `Ctrl + O` 选择该文件。
3. 地址栏形如 `file:///D:/打字练习网站/index.html`，此时已完全可用。

> 项目目录已创建桌面快捷方式 `打字练习网站.lnk`，双击即可用默认浏览器打开该页面。

### 方式 B：用本地静态服务器打开（可选）

如果希望以 `http://` 协议访问（例如需要与其他页面同源联调）：

```powershell
cd D:\打字练习网站
python -m http.server 8000
# 然后访问 http://localhost:8000/index.html
```

### 方式 C：备份你的练习数据

浏览器数据保存在 `localStorage`，键名为 `jiancheng.typing.v1`。需要迁移或备份时：

1. 在「数据统计」页点击**导出记录**，会下载 `jiancheng-typing-export.json`，内容形如：

   ```json
   {
     "app": "键程打字练习",
     "exportedAt": "2026-10-14T01:23:22.000Z",
     "data": { "version": 1, "settings": {}, "history": [], "keyStats": {}, "customTexts": [], "lessonBest": {}, "totals": {} }
   }
   ```

2. 迁移到新环境时，把该 JSON 中 `data` 字段的值写回新浏览器的 `localStorage`（键名 `jiancheng.typing.v1`），刷新页面即可恢复历史与素材。

   > 注意：当前版本的界面只提供**导出**，没有内置的"一键导入 JSON"按钮。如果浏览器禁用了 localStorage（如部分隐私模式），程序会自动退化为内存存储，本次记录在关闭页面后不保留。

## 4. 使用方法

### 4.1 快速开始（60 秒）

1. 打开 `index.html`，页面默认停在**练习模式**。
2. 在「练习内容」下拉框选择一课（例如 `LEVEL 1 · 基准键位 asdf jkl;`）。
3. 直接在键盘上开始输入——**无需点击输入框**，敲下第一个键时自动开始计时。
4. 文本区会逐字符给出正确 / 错误 / 当前位置的反馈，顶部实时显示速度与正确率。
5. 打完整段后弹出「完成」浮层，下方结果面板列出净速度、正确率、用时、击键/错误数与逐字错误明细（最多 12 条）。
6. 点击「再练一遍」或按 `Ctrl + Enter` 重开，也可按「查看文本」回到全文。

### 4.2 分级课程怎么用

「分级课程」页 → 点击任意课程的「练习」按钮 → 自动切回练习模式并载入该课文本。星级取历史最佳成绩，多练不会掉星；「继续上次」直接回到最近一次课程练习。

### 4.3 专项训练怎么用

- **易错键强化**：在「专项训练」页查看当前弱键，点「生成练习」把错键编成练习串。
- **提速冲刺**：先选 60 / 120 / 180 秒，再点「开始冲刺」，倒计时结束自动结算。
- **盲打强化**：勾选要隐藏的内容（文本 / 键盘），点「进入盲打模式」，按任意键或点「开始」后凭记忆输入。

### 4.4 用自己的材料练习

「素材库」页 → 在「粘贴练习文本」中粘贴内容（≥ 20 字符）→ 可填标题（留空自动命名为「自定义素材」）→ 点「保存到素材库」。保存后的素材会出现在下方列表（可练习 / 删除）以及练习模式的下拉框中。

### 4.5 考试模拟怎么用

「考试模拟」页 → 选时长（3 / 5 / 10 分钟）与范围（综合 / 英文段落 / 中文段落 / 代码片段）→ 点「开始考试」→ 计时作答（过程中不看对错）→ 点「提前交卷」或等倒计时归零 → 查看成绩单与错误明细。

### 4.6 键盘快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + 1…7` | 在七个主视图之间切换 |
| `Ctrl + Enter` | 重新开始当前练习（仅在练习视图生效） |
| `Ctrl + M` | 开关键击音效 |
| `Ctrl + K` | 显示 / 隐藏虚拟键盘 |
| `Esc` | 关闭弹层 · 暂停游戏 · 退出输入区（同时会关闭弹层） |
| `Tab` | 浏览器原生焦点切换（未拦截，依次聚焦侧栏与工具按钮） |

> 说明：除上表外，页面没有为 `Tab` 编写拦截逻辑，它是浏览器自身的焦点导航行为；`Enter` 也不是功能快捷键，而是作为练习文本的换行字符被输入（详见 4.7 与 4.8）。

侧栏底部的图标可分别切换主题、音效、练习偏好、快捷键说明。

### 4.7 中文与英文练习的差别

- **英文内容**：直接键盘输入，速度以 WPM 呈现。
- **中文内容**：使用系统拼音输入法整字上屏，程序在 `compositionstart` / `compositionend` 期间不打断输入法，速度以「字/分」呈现，错误归因到字符级（不强行归因到物理键）。
- 代码素材中的换行需要按 `Enter` 输入，换行位置同样参与逐字符比对。
- **`Enter` 是文本字符而非快捷键**：在全站范围它用于关闭弹层，但在练习输入区内它被当作换行字符处理——因此练习单行文本时误按 `Enter` 会记为一次错误输入（回退用 `Backspace` 删掉即可），这也是代码类素材能正常练习换行的原因。
- 单个字符（含中文）的比对严格区分大小写与全半角标点：`，` 与 `,`、`；` 与 `;` 属于不同字符。

### 4.8 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 打字没有反应 | 页面失焦后输入区会失去焦点，点击文本区域任意位置即可重新聚焦 |
| 刷新后记录还在吗 | 在，数据存于本机 `localStorage`；隐私模式或禁用存储时退化为内存存储，关闭页面即丢失 |
| 换电脑后记录没了 | 数据不联网、不上传，请用「数据统计 → 导出记录」备份 JSON |
| 「易错键强化」提示数据不够 | 该功能需要至少若干个错键样本（同一键位累计 ≥ 3 次击键且出现错误），先完成几组练习或一次考试 |
| 想彻底清空数据 | 「数据统计」页点「清空数据」，需二次确认 |
| 误按 `Enter` 后出现错误 | 练习输入区内 `Enter` 被视为换行字符，单行文本会记一次错误；按 `Backspace` 删除即可，或用「重开」重来 |
| 中文标点总是判错 | 比对区分全角与半角，请用与素材一致的全角标点（`，。、；：` 等） |

## 5. 输入输出示例

### 5.1 练习模式：整段输入示例

**输入**（课程 `LEVEL 1 · 基准键位 asdf jkl;`，用户依次敲键）：

```
a s d f   j k l ;   a s d f   j k l ;   f j d k   s l a a
```

**输出**（练习完成后界面展示的真实字段）：

```
完成浮层：  48 WPM · 正确率 97.2% · 用时 00:14
结果面板：
  净速度        48 WPM
  正确率        97.2 %      按击键统计
  用时          00:14
  击键 / 错误   62 / 2
错误明细（最多 12 条）：
  #12  期望「d」  输入「s」
  #31  期望「k」  输入「j」
本次弱键： d · 1 次   k · 1 次
```

### 5.2 逐字符实时反馈示例

以课文 `今天天气很好，适合出门散步。` 为例，用户输入到第 6 个字符时把「好」误打成「起」，界面状态为：

| 位置 | 字符 | 状态 |
| --- | --- | --- |
| 1–5 | `今天天气很` | 正确（正常字色） |
| 6 | `好` | **错误**（错误色 + 下划线，因为此处输入了「起」） |
| 7 | `，` | 当前位置（光标高亮） |
| 8–14 | `适合出门散步。` | 待输入（弱化字色） |

顶部指标同步更新为：`剩余 01:12 · 62 字/分 · 正确率 94%`。

### 5.3 自定义素材：输入与产物

**输入**（素材库 → 粘贴练习文本）：

```
标题：产品需求文档节选
正文：本系统面向一线客服人员，支持工单创建、流转与归档。所有操作均记录审计日志，便于事后追溯与质量复核。新员工需完成三小时培训后方可独立处理客户工单。
```

**输出**：

```
提示条： 已保存 1 条素材
素材列表：
  产品需求文档节选
  71 字 · 10 月 14 日 09:23        [练习] [删除]
练习内容下拉框：新增分组「自定义素材」→ 产品需求文档节选
```

若正文超过 600 字符并含空行分段，会自动拆成多条素材，标题后缀「· 第 1 段 / 第 2 段…」。

### 5.4 提速冲刺：输入与产物

**输入**：时长选 `120 秒` → 点「开始冲刺」→ 连续输入由高频英文词表生成的文本。

**输出**：

```
倒计时结束 → 自动结算
  净速度        96.4 WPM
  正确率        95.1 %
  用时          02:00
  击键 / 错误   1043 / 51
```

若提前打完生成的词表，练习会在文本末结束；未打完则计时归零时结算，两种路径都进入同一结果面板并写入历史。

### 5.5 单词雨游戏：输入与产物

**输入**：难度 `标准` → 点「开始游戏」→ 在单词落到基线前键入 `bridge`、`coffee`…（`Backspace` 可修正，`Esc` 暂停）。

**输出**（结束浮层）：

```
得分 1240 · 击落 18 · 最高连击 9
```

该局同时写入历史记录（模式 `单词雨 · 标准`），并计入「练习次数 / 累计时长」。

### 5.6 考试模拟：输入与产物

**输入**：时长 `5 分钟`、范围 `综合（英文 + 中文）` → 点「开始考试」→ 计时内尽力输入 → 提前交卷。

**输出**（成绩单）：

```
综合 · 5 分钟 · 用时 04:37 · 完成 412 字
评级  B
  净速度        58.2 WPM
  正确率        93.6 %
  完成字数      412 / 1900
  击键 / 错误   2264 / 145
错误明细：145 处
  #37   期望「e」  输入「r」
  #88   期望「，」  输入「、」
  ...
操作： [再考一次]  [用这份试卷练习]
```

> 评级口径：`净速度 × 正确率 ÷ 100` ≥ 70 为 A，≥ 50 为 B，≥ 30 为 C，其余为 D。成绩仅供自我参考，不构成任何资质认证。

### 5.7 数据统计：输入与产物

**输入**：完成若干次练习 / 游戏 / 考试后进入「数据统计」页。

**输出**：

```

平均正确率    95.4 %        最近 30 次
累计练习      86 分钟       全部记录
练习次数      34            含游戏与考试
最佳速度      71.8 WPM      历史峰值

速度与正确率趋势：最近 14 次的 SVG 双线折线图（附隐藏数据表）
错误类型分布：相邻键误触 62% · 大小写 18% · 标点 12% · 其他 8%
键位热力图：错误越多的键颜色越深
弱键排行： 键位 | 击键 | 错误 | 错误率 | 占比
最近记录： 时间 | 模式 | 内容 | 速度 | 正确率 | 用时
```

无任何记录时，趋势图与弱键区域会显示引导文案（空状态），不会出现占位或编造的数据。

`index.html` 内部分区（便于二次修改定位）：

| 位置 | 内容 |
| --- | --- |
| `<head>` 内联脚本 | 首帧前应用主题，避免闪烁 |
| `<style>` | 莫兰迪种子 token（`--seed-*`）+ 语义/组件层样式 + 深色主题 + 响应式断点 |
| SVG `<symbol>` | 全部界面图标（内联，无外链） |
| `<div class="app">` | 侧边栏 + 七个视图的标记 |
| `COURSES` / `LIBRARY` / `GAME_WORDS` | 课程、素材库与游戏词库数据 |
| `TypingEngine` | 打字引擎：逐字符比对、统计、限时、盲打、IME 兼容 |
| `game` / `exam` | 单词雨与考试模拟流程 |
| `renderStats` 等 | 统计页图表、热力图与记录表渲染 |
| `loadState` / `saveState` | `localStorage` 持久化与损坏数据回退 |

## 7. 开发与自定义

- **改课程内容**：编辑 `index.html` 中的 `COURSES` 数组（`id` / `no` / `name` / `desc` / `lessons[]`，每课含 `id`、`name`、`lang`、`text`）。
- **改内置素材**：编辑 `LIBRARY` 数组，`cat` 取值 `article` / `code` / `doc` / `poem` / `pro`。
- **改配色**：只修改 `:root` 与 `[data-theme="dark"]` 中的 `--seed-*` 变量，其余颜色均由它们派生。
- **重置数据**：清空浏览器中键名 `jiancheng.typing.v1` 的 localStorage 项，或在「数据统计」页点「清空数据」。

## 8. 已知边界

- 单词雨游戏使用英文词库（中文词表未接入游戏流程）。
- 自定义素材通过粘贴导入；文件上传与 JSON 反向导入未在界面中提供。
- 数据仅存于当前浏览器，不跨设备同步。
- 考试评级仅为自我参考，不具备任何认证效力。
